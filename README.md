# نظام إدارة المخزون والمتجر الإلكتروني (Inventory Management System)

## 📌 اسم المشروع
نظام إدارة المخزون والمتجر الإلكتروني

## 📝 وصف المشروع
مشروع ويب متكامل مصمم لإدارة المنتجات والمخزون وعرضها للعملاء، يتيح للمستخدمين تصفح المنتجات والبحث فيها وتصفيتها حسب الأقسام، بالإضافة إلى لوحة تحكم خاصة للآدمن لإدارة المخزون والمنتجات بسهولة (إضافة، تعديل، حذف).

## 💡 فكرة المشروع
تقديم منصة إلكترونية مبسطة وعملية لأصحاب التجارة والأعمال لإدارة منتجاتهم ومتابعة كميات المخزون بشكل منظم وسلس، مع توفير واجهة عرض جَذّابة وسريعة للمتسوقين.

## 🛠️ طريقة التشغيل (Local Setup)
1. قم بتشغيل سيرفر محلي مثل **XAMPP** أو **WAMP**.
2. ضع مجلد المشروع داخل مسار خادم الويب (مثلاً `htdocs` في XAMPP).
3. شغل خدمتي **Apache** و **MySQL** من لوحة التحكم.
4. افتح المتصفح وادخل إلى `http://localhost/phpmyadmin`.
5. قم بأنشاء قاعدة بيانات جديدة باسم `inventory_db`.
6. قم باستيراد (Import) ملف قاعدة البيانات `inventory_db (2).sql` المرفق داخل المشروع.
7. افتح الموقع عبر الرابط: `http://localhost/inventory_system/index.php`.
