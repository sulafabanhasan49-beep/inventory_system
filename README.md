# نظام إدارة المخزون الذكي (Inventory Management System)

## 🏢 الكلية والأقسام المعتمدة
* **الكلية:** كلية الإدارة والتمويل
* **طبيعة المشروع:** نظام ويب ديناميكي لحل مشكلات التتبع والرقابة على حركة المنتجات والمستودعات.

## 📝 وصف وفكرة المشروع
مشروع تقني مصمم كحل إداري رقمي متكامل لمساعدة المؤسسات والمتاجر على إدارة ومراقبة المخزون السلعي بدقة وعرض المنتجات وتصنيفاتها. يوفر النظام لوحة تحكم شاملة للمسؤول (Admin Dashboard) تتيح تتبع الكميات المتاحة في المستودعات، تحديث الأسعار، وحماية البيانات اللوجستية لمنع العجز أو الهدر السلعي.

## 🛠️ المميزات البرمجية والإدارية للنظام
* **لوحة تحكم كاملة للمسؤول (Admin Dashboard):** لمتابعة حالة المخزون والعمليات اللوجستية مباشرة.
* **إدارة كاملة للبيانات (CRUD Operations):** إمكانية (إضافة منتج جديد، استعراض المنتجات المتاحة، تعديل تفاصيل الأسعار والكميات، وحذف السجلات).
* **نظام حماية وإدارة الجلسات (Sessions & Security):** تأمين الصفحات الداخلية ومنع الدخول غير المصرح به، مع ميزة تسجيل الخروج الآمن (Logout).
* **رفع وإدارة الصور:** دعم رفع الصور المباشرة للمنتجات داخل المستودع وعرضها هندسياً في الواجهة بشكل منسق.

## 🗄️ هيكل قاعدة البيانات (Database Architecture)
تتكون قاعدة البيانات المعتمدة للنظام من **5 جداول متكاملة ومترابطة** لتحقيق متطلبات الإدارة والنظم:
1. `users`: لإدارة بيانات المستخدمين وتوزيع الصلاحيات وأدوار الدخول.
2. `products`: لتخزين سجلات المنتجات، الأسعار، الكميات، والروابط الخاصة بالصور.
3. `categories`: لتصنيف المنتجات وتسهيل عمليات الفرز والبحث المستودعي.
4. `orders`: لتسجيل وتتبع حركات الطلبات الصادرة والواردة.
5. `order_details`: للاحتفاظ بالتفاصيل الدقيقة والكميات لكل طلب مدخل.

## 🚀 طريقة تشغيل النظام
1. تأكد من تشغيل خادم الـ **Apache** وخادم الـ **MySQL** من لوحة تحكم برنامج *XAMPP*.
2. ضع مجلد المشروع بالكامل `inventory_system` داخل المسار المعتمد: `C:\xampp\htdocs\`.
3. قم باستيراد ملف قاعدة البيانات المرفق `inventory_db.sql` عبر واجهة الـ *phpMyAdmin*.
4. افتح المتصفح وتوجه إلى الرابط التالي لتشغيل واجهة النظام:
   `http://localhost/inventory_system/login.php`
